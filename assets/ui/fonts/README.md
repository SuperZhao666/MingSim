# 中文字体策略

字体负责把御书房、奏疏与舆图的中国传统审美落实到真实可读文本中。所有汉字均由 Godot 运行时排版，不烧录进生成图片，也不通过伪书法贴图替代可访问文本。

## 运行时优先级

- 标题、题签、奏疏名和重要地名：运行时优先请求系统楷体族，例如 `华文楷体 / KaiTi / 楷体`。
- 奏疏正文、说明、数值和较长段落：运行时优先请求系统仿宋族，例如 `华文仿宋 / FangSong / 仿宋`。
- 小字号地图标签以清晰为先；可在仿宋与系统中文衬线字体之间按实际像素可读性选择，不为追求书法感牺牲辨识度。
- 系统缺少首选字体时，回退到可用的中文衬线字体，再回退到 Godot / 操作系统默认中文字体；不得因缺字显示方框或乱码。

## 仓库分发边界

- 楷体、仿宋及其他操作系统字体**仅作为运行时优先选择**。
- Windows 自带或其他来源不明的字体文件不复制、不提交，也不随仓库分发；本目录只保存策略说明，不保存这些字体二进制。
- 字体名称列表不等于字体授权。即使开发机可以调用，也不能据此认定项目拥有再分发权。
- 若未来需要跨平台像素级一致，必须另行选定、记录并核验可再分发的开源中文字体；在完成授权和字形覆盖检查前，不把候选字体文件加入仓库。

## 排版约束

- 题签与标题可使用楷体营造手书气息，正文使用仿宋保持奏疏、册页和版刻文本的阅读节奏。
- 朱色只承担批示、印记、选中和紧急层级；普通正文保持墨色，不使用发光描边、亮金字或现代无衬线大标题破坏氛围。
- 地图文字直接落在对应地块 / 地理空间中，按 CK3 式 LOD 分级显示，并参与标签碰撞；不得把所有城镇名同时显示，也不得使用白色矩形底框覆盖地图。
- 字号、字重和字距必须服从缩放层级与信息优先级：远景保留国号 / 省域，中景出现治所 / 重镇，近景才出现府州县镇。
