# UI 概念图

这里保存由 ImageGen 生成、用于讨论视觉方向的概念图。

概念图不是可直接交互的 Godot 控件，也不是历史地图数据。接入游戏前必须拆分为：

- 程序生成的地图几何；
- Godot `Control` 控件；
- 可九宫格拉伸的面板材质；
- 独立 SVG 图标；
- Godot 实际渲染的文字和数值。

任何概念图都不得承担政治边界、城市经纬度、运输路线或点击 ID。

### `ming-imperial-map-ui-direction-v1.png` 的生成提示词摘要

用途分类：`ui-mockup`。要求生成 16:9、直视角的晚明御案式战略界面；中央保留约 70% 无遮挡地图视窗，周围包含空白顶部状态栏、左侧奏疏栏、右侧详情栏、底部命令区和图层选择区；材质为宣纸、暗色漆木、旧铜和克制朱砂。明确禁止文字、数字、旗帜、Logo、人物、海岸线、政治边界、道路、城市以及任何虚构地理。

这张图只作为视觉方向稿，后续必须在 Godot 中用真实控件和通过审核的历史地图数据重新实现。
