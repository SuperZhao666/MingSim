# ADR-006：AI 是按需的外围决策源

状态：Accepted  
日期：2026-08-13

## 背景

早期设想让每个角色拥有独立常驻子代理，但上万人物持续调用模型会造成成本、延迟、上下文和一致性失控。项目又希望重要人物有开放式谋略和语言，而不是完全固定脚本。

## 决定

关键人物保存持久身份、目标、Belief 和记忆，但 LLM 只在重大认知事件按需唤醒；日常人物用 Utility AI/规则，普通人口使用 Cohort。Agent 只返回白名单 Structured Intent，Simulation 重新验证后才能执行。0 次模型调用时 MVP 必须完整可玩。

## 原因

- 让概率系统与权威状态隔离；
- 控制成本和延迟；
- 支持离线和模型故障回退；
- 模型提供真正擅长的开放式决策/表达；
- Replay 无需重新调用模型。

## 代价

- 需要 Context Compiler、期限/版本和结构化解析；
- 人物日常行为要有可靠 Utility AI；
- 模型返回可能过期，必须丢弃或重校验；
- AI 表现受玩家模型配置影响，需要明确降级状态。

## 被否决方案

- 每人物常驻模型：成本和调度不可控；
- 一个全知总模型模拟世界：破坏有限认知和单一状态；
- 完全不用模型：能做核心玩法，但损失关键人物开放式表达；
- 引入大型 Agent 框架：当前薄适配器即可满足边界。

## 何时重新评估

只有完成纵切的成本、延迟和试玩数据证明扩大模型覆盖会显著提升玩法，并且不破坏离线与确定性边界时重评。

## 验证

- 断网完整通关；
- 非法/越权/过期/重复输出拒绝；
- 模型文本不改状态；
- API 预算耗尽自动回退；
- Replay 不联网。
