# 1629 辽东—辽西史实态势证据账本

> 用途：宁远急饷垂直切片的历史证据和地图语义审计。快照标签暂定 `1629-01-01`。
> 本文只授权“证据层”和“地图表现规则”，不直接授权修改 `content/scenarios/ming_1629/map/` 或正式游戏边界。

## 结论先行

这份账本把“史料明确说了什么”和“地图为了可玩而怎么抽象”分开：

- 可以进入 P0 的，是山海关、宁远、锦州、登州等节点，以及有史料支持的关宁锦守援/转输拓扑、东江镇海岛—辽南沿岸节点网络、后金辽沈核心的有限淡色表达。
- 不能进入 P0 精确政治面的是关宁锦外沿、辽沈核心外沿、东江镇对辽南陆地的持续控制范围、双方争夺区宽度，以及任何由现代省界补出的边线。
- Hartwell 1391 只能作为研究基线，绝不能写成 1629 年的实际控制；CHGIS 当前只记录许可边界，不能把其几何打包进游戏。
- `FACT` 只表示来源直接支持限定断言；`INFERENCE` 是可替换的制图/玩法归纳；`OPEN` 表示不能写死。

机器可读主账本见 [`liaodong-1629-evidence.json`](../../content/scenarios/ming_1629/evidence/liaodong-1629-evidence.json)。

## 2. 关键 FACT

### 2.1 关宁锦是节点—走廊网络，不是连续省界

`FACT-GUANNINGJIN-NETWORK`：CText 的《锦宁战守》将宁远称为关门要害，记载山海关、宁远、前屯、锦州的驻守/援应安排，并提到“三路哨探远出锦右”。这直接支持“城、关、堡、哨探和转输构成网络”，不直接支持一条精确外边线。

地图表现：山海关、宁远、锦州用精确点或近似点；宁远—山海关—锦州只画示意走廊。不要显示古代路线的精确宽度、里程、运输天数或容量。

`FACT-NINGYUAN-FRONTIER`：同一史料记载天启六年建州兵攻宁远、守军凭城拒却，并说“宁远至山海一线可通转输易足”。这支持宁远是前线和转输关系节点，但不是 1629-01-01 当日驻军、库存或城墙测绘证明。

`FACT-JINZHOU-FRONTIER` 与 `FACT-SHANHAIGUAN-GATE`：锦州和山海关在守援叙述中与宁远、前屯并列，因此可以进入 P0 节点语义；周边精确控制面保持 `OPEN`。

### 2.2 宁远急饷与登莱海运关系

`FACT-NINGYUAN-TRANSIT`：原始史料记载崇祯二年三月曾议在宁远设置东江饷司，并令东江自觉华岛转饷；五月又记毛文龙赴登州请饷。这是事件后的关系证据，不得回填成 1629 年初已执行的固定路线。

`FACT-DENGZHOU-LIAODONG-LINK`：史料还记载崇祯元年八月毛文龙因风泊登州，且将登莱、旅顺、朝鲜放在海上军务关系中。登州可作为近似港口节点，登州—辽南方向可有淡色候选海运线；真实中继、航季、时长、运力、风险全部 `OPEN`。

### 2.3 东江镇：能证明的是网络节点，不是辽南连续领土

`FACT-DONGJIANG-NODES`：崇祯二年六月前的《毛帅东江》明确出现东江总兵毛文龙，以及皮岛/须弥岛、双岛、觉华岛、旅顺、登州、金州、复州、海州和朝鲜方向的关系。可以证明东江镇至少包含海岛、港口、辽南沿岸和海上联络节点。

地图表现：岛屿/港口用点，节点之间用网络或淡色影响区；不涂成现代式省份，不画“东江镇稳定控制整个辽南陆地”。毛文龙在崇祯二年六月被杀，年初与六月后的组织关系必须按事件/日期层切换。

### 2.4 后金辽沈核心

`FACT-LIAOSHEN-LATER-QING-CORE`：辽宁省文旅厅官方遗址说明记载后金天命六年（1621）攻下辽阳、建东京城，天命十年（1625）三月迁都沈阳；东京城随后设章京守护。这足以否定“1629 辽沈腹地仍是明军稳定实际控制”的表达。

地图表现：东京城/辽阳/沈阳用近似点，核心只可用有限淡色影响区；不能从一座都城遗址直接推导精确外沿，也不得使用 Hartwell 1391 行政几何补齐 1629 面。

### 2.5 四座历史城址的证据边界

| 节点 | 本轮能确定的语义 | 可画 | 仍然 OPEN |
| --- | --- | --- | --- |
| 山海关 | CText 明确称关门/要害，并纳入宁远—前屯—锦州守援结构 | 关口近似点；关宁锦示意走廊 | 1629 城墙中心、关城范围、驻军、仓储、容量 |
| 宁远 | CText 明确记载宁远城防、前线战事和向山海一线转输关系 | 前线近似点；宁远—山海关走廊 | 古城墙精确轮廓、快照日驻军、库存和日耗 |
| 锦州 | CText 在关宁锦守援/攻守叙述中多次与宁远、前屯、山海关并列 | 前沿近似点；宁远—锦州方向示意走廊 | 历史城址精确中心、1629 当日控制与周边边线 |
| 登州 | CText 记载泊登州、赴登州请饷，并涉及登莱海上军务 | 港口近似点；登州—辽南淡色候选线 | 古港/城址范围、实际航线、中继、航季、运力 |

本表的“近似点”不是现代 GPS 对古城墙的证明。若沿用项目已有现代锚点，必须标注 `modern_anchor`/`anchor_only`，不得显示为精确古代几何。

## 3. INFERENCE：允许的制图归纳

### 3.1 关宁锦走廊

北京—通州—山海关—宁远—锦州可作为 P0 的陆路拓扑，依据是关宁锦节点的守援关系和宁远—山海转输语句。北京—通州的具体漕运仓储/运力、宁远—锦州中间点和道路几何没有在本轮闭合，因此这条线只能是示意走廊。

### 3.2 后金辽沈核心

东京城—辽阳—沈阳方向可做淡色核心影响区，来源支撑的是都城和迁都事实，地图归纳不应伪装成 1629 精确主权边界。

### 3.3 东江海岛网络

东江镇采用“岛屿—港口—沿岸据点—海路关系网”表达。它是军事网络/影响层，不是行政面。无法证明持续控制的陆地、争议岛屿外沿和活动半径保持 `OPEN`。

## 4. OPEN 与禁止绘制

以下对象目前只能保留研究任务，不能进入精确 P0 图层：

1. 关宁锦外沿、后金辽沈核心外沿、东江镇对辽南陆地的持续控制范围和双方争夺带的精确边线；
2. 北京—通州—山海关—宁远—锦州的精确道路、里程、时长、容量；
3. 登州—辽南海运的直达线、中继岛、航季、风险和运力；
4. 山海关、宁远、锦州、登州四城的 1629 城墙中心/轮廓，除非补齐逐城权威遗址或考古来源、坐标方法、图号/页码和许可；
5. 任何现代省界、GADM/geoBoundaries Admin-1、Natural Earth Admin-1 或来源不明网友矢量；
6. Hartwell China Historical GIS Ming 1391 行政几何作为 1629 实际控制；
7. CHGIS 原始或修改几何，直到获得符合其协议的书面许可；
8. LOC 三份馆藏地图的图像描边，直到目录/图页和权利行通过人工复核。

## 6. 来源与许可证裁决

- CText：用于原始史料链接、短引和定位；不复制扫描图或整库。
- 辽宁省文旅厅：用于官方遗址事实引用；页面图片没有在本条目中取得再分发授权。
- LOC：馆藏目录是待复核线索。本轮 Cloudflare 403，不能把未核验的权利行写成已确认许可。
- CHGIS：复旦页面明确非商业学术/教育限制、部分使用需许可、不得未经书面同意整库再发布；因此只做许可审计，禁止打包几何。
- Natural Earth、Hartwell、现代行政数据不在本账本中充当 1629 控制证据；特别是 Hartwell 1391 不得称作 1629 实际控制。

## 7. 机器校验约定

运行校验应确认：JSON 可解析；所有 `FACT` 记录有 `source_ids`；每个来源 URL 有访问结果；`OPEN` 不进入 P0 精确几何；`forbidden_to_draw` 明确现代省界、Hartwell 1391、CHGIS 和未核验古图的禁用边界。

详细字段、断言 ID、来源定位和许可证状态以 JSON 为准；任何未来地图对象必须反向引用 `claim.id`，没有引用的对象只能保持草稿。
